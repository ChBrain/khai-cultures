# Order: a Name Reads as Prose

**A link is named with the words the sentence would use anyway. The filename is
an address, and an address is not a name.**

`order_an_address_resolves.md` asks whether the thing on the other end of a link
exists. It never asks what the link is called, and the two are different
questions. This one resolves perfectly:

```
The pitch [pitch_corsica.md](pitch_corsica.md) is written from France's profile
```

It resolves, it passes twelve walls, and it stops the sentence dead. A reader
who is reading, rather than navigating, has just been handed a file path in the
middle of a clause.

## What the house reads like today

Measured over every markdown link a unit ships:

| links  | name repeats the file | of those, registers | of those, prose |
| ------ | --------------------- | ------------------- | --------------- |
| 41,944 | 6,129                 | 5,494               | **635**         |

The 635 are the whole fault, and they are in two files:

| file            | findings |
| --------------- | -------- |
| `REFERENCES.md` | 330      |
| `README.md`     | 305      |

**Every play, plot, persona, place, piece, position and process in the house
carries zero.** The voice was already right where the voice is the product. What
drifted is the two files nobody reads aloud.

## The two sentences

The 635 are not 635 decisions. They are two sentences repeated across some six
hundred packages, and the first one hands over its own repair — the natural name
is already sitting in the clause, one word to the left:

| today                                                             | named                                                  |
| ----------------------------------------------------------------- | ------------------------------------------------------ |
| `The pitch [pitch_corsica.md](pitch_corsica.md) is written from…` | `[The pitch](pitch_corsica.md) is written from…`       |
| `…sources are documented in [REFERENCES.md](REFERENCES.md).`      | `…sources are [documented separately](REFERENCES.md).` |

## A register is not prose

A row in the REFERENCES table, a `- **Anchor:**` line in a README, a bare
`[play_bern](play_bern.md)` alone on its line: in all three the filename **is**
the information the reader came for, and renaming it would destroy the thing
being given. There are 5,494 of them and not one is a fault.

Counting them anyway would be building a counter, and
`order_the_passport.md` tells this house not to build one. So the question is
asked of sentences only, and a line is a sentence when, with its links taken
out, three words of it are still standing.

## Why it is a ratchet

`staging` is absolute because it started clean. `group-ratchet` is a ratchet
because it started at seventy. `links` is a ratchet because its three cannot be
repaired without authoring unrelated content.

This one starts at 635, and the argument is neither of those. The prose that
matters started clean, which argues for absolute. The 635 argue against: they
live in two files per package across some six hundred packages, and a wall that
turns red on six hundred packages the day it lands is a wall that gets bypassed.

So it reports the whole house and blocks on the units a change actually wrote.
Touch a README, clean its names. The only units it can ever charge are ones the
author already had open.

## It does not charge the undermined

`links` charges a unit when somebody else's move breaks ground it points onto,
because a path can go dead without its author touching it.

A name cannot. It changes only when the sentence holding it is rewritten. So
this wall reads `charged()` for `written` alone, and a migration that moves a
thousand files charges nobody here.
