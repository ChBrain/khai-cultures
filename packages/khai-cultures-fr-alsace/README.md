# fr_alsace

This package stages Alsace for the khai content house: the land between two
states that changed sides five times between 1681 and 1945, and that was made to
prove, each time, that it had always belonged to whichever one had just arrived.

The content is written in Alsatian (`gsw`), the tongue the culture stages, and
the culture-position nests on France. See [REFERENCES.md](REFERENCES.md) for the
sources, for the defining question, for why `geo.json` carries a `covers`, and
for the standing note on who has read the Alsatian.

See the root for instructions.
