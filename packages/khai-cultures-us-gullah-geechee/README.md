# us_gullah_geechee

This package stages the Gullah Geechee for the khai content house: the people of
the Sea Islands and the Lowcountry, from the Carolina rice coast down into
Georgia and Florida.

It is a **mapless culture**. It carries no `geo.json`, holds no ISO code, and is
not painted on any map, because the ground it lives on is already painted as
South Carolina and Georgia. It nests in one parent, `usa`, and has no kin
abroad: what it holds was made here. See
`management/orders/order_a_culture_without_a_map.md`.

The prose is in Gullah, the orthography of _De Nyew Testament_ (2005). The tongue
itself is `@chbrain/khai-cultures-tongues/gul/`.
