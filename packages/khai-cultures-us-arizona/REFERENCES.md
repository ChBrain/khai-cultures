# Arizona: References

The provenance behind this culture: the Hofstede source data that tunes the pitch (kept here, never in the prose) and the public-domain historical sources behind the plots, personas, places, and pieces.

## Hofstede source data

The pitch [the Arizona key](pitch_arizona.md) is written from Arizona's profile inflected by its desert environments, mineral resources, Native American histories, and modern solar expansion, naming no dimension and carrying no number.

| Dimension                     | Arizona base score (estimated / US proxy) |
| ----------------------------- | ----------------------------------------- |
| Power Distance                | 36                                        |
| Individualism                 | 80                                        |
| Motivation toward Achievement | 64                                        |
| Uncertainty Avoidance         | 42                                        |
| Long Term Orientation         | 28                                        |
| Indulgence                    | 64                                        |

Source: Geert Hofstede, Hofstede Insights (US comparison, adjusted for Arizona's desert self-reliance, tribal communal networks, and low power distance in local land management).

## What moved out, and why

Navajo weaving, the rug and the code talkers plot were staged in this package
before `us_navajo` existed, and they are Diné rather than Arizonan. They now
live in `@chbrain/khai-cultures-us-navajo`: weaving and the rug as that
culture's own files, the code talkers as its `plot_06`, staged from the
language rather than from the Corps.

`management/orders/order_a_culture_without_a_map.md` names the old shape here
by filename and calls the line fair inside Arizona but wrong as the only place
the Diné appear in the house. That second condition ended when `us_navajo`
shipped, so what is corrected here is the first: Yazhi's belonging now points
at the Diné way. She stays, because an Arizona with no Diné person in it would
be false in the other direction.

The plot line is shorter by one and is not backfilled. Four plots on water and
extraction is what this state's staging honestly holds at present, and inventing
a fifth to keep a count would be worse than the gap.
