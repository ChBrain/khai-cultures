# us_navajo

This package stages the Diné for the khai content house: the people of the land
between the four mountains, whose nation spans the corner where Arizona, New
Mexico and Utah meet.

It is a **mapless culture**. It carries no `geo.json`, holds no ISO code, and is
not painted on any map. It nests in one parent, `usa`, and has no kin: the host
formed around this people rather than this people arriving inside the host. The
reservation is real, large and bounded, and it still cannot be painted, because
it crosses three state fills and holds no code of its own. No geo, no fill. See
`management/orders/order_a_culture_without_a_map.md`.

The tongue is `@chbrain/khai-cultures-tongues/nv/`, which this package links and
does not carry.

The prose is in English, and unlike `us_catawba` **that is a fallback and a debt
rather than a description**. `REFERENCES.md` says why, and what is owed.
