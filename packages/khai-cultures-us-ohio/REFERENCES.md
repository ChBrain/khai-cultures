# Ohio: References

The provenance behind this culture: the Hofstede source data that tunes the pitch (kept here, never in the prose) and the public-domain historical sources behind the plots, personas, places, and pieces.

## Hofstede source data

The pitch [pitch_ohio.md](pitch_ohio.md) is written from Ohio's profile inflected by its history of heartland farming, industrial development, and aviation engineering, naming no dimension and carrying no number.

| Dimension                     | Ohio base score (estimated / US proxy) |
| ----------------------------- | -------------------------------------- |
| Power Distance                | 38                                     |
| Individualism                 | 88                                     |
| Motivation toward Achievement | 63                                     |
| Uncertainty Avoidance         | 48                                     |
| Long Term Orientation         | 25                                     |
| Indulgence                    | 65                                     |

Source: Geert Hofstede, Hofstede Insights (US comparison, adjusted for Ohio's working-class union heritage, agrarian community focus, and moderate uncertainty avoidance in manufacturing safety).
