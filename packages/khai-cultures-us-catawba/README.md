# us_catawba

This package stages the Catawba for the khai content house: the river people of
the Carolina Piedmont, Yap Ye Iswa, whose nation sits near Rock Hill in South
Carolina.

It is a **mapless culture**. It carries no `geo.json`, holds no ISO code, and is
not painted on any map. It nests in one parent, `usa`, and has no kin: the host
formed around this people rather than this people arriving inside the host. See
`management/orders/order_a_culture_without_a_map.md`.

The prose is in English, because English is what the Catawba speak. It is not a
fallback here. The Catawba language, `chc`, has no file in
`@chbrain/khai-cultures-tongues` and this package links none; `REFERENCES.md`
says why.
