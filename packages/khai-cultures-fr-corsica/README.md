# fr_corsica

This package stages Corsica for the khai content house: the island that was a
republic with a constitution and a university fourteen years before it was a
French department, and that has argued about the manner of belonging ever since.

The content is written in Corsican (`co`), the tongue the culture stages, and
the culture-position nests on France. See [REFERENCES.md](REFERENCES.md) for the
sources, for the defining question, and for the standing note on who has read
the Corsican.
