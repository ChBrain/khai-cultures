**Plot Zero: every culture answers where it comes from.**

The defining question catches gaps in the middle of a plot line, because a reader
notices those. It does not catch the floor, and nothing looks missing below the
first plot. Measuring the earliest date in each culture's opening Cue, across all
290:

| opening       | cultures |
| ------------- | -------- |
| antiquity     | 2        |
| before 1000   | 6        |
| 1000–1499     | 23       |
| 1500–1799     | 28       |
| 1800–1899     | 36       |
| 1900 or later | 8        |

**Berlin opened at the Wall** — founded around 1237, capital of Prussia, capital
of Weimar — because 1961 is the first date a state history of Berlin finds
interesting. Bavaria opened when Napoleon made it a kingdom. The two cultures
opening in antiquity are the two restaged the day this was measured.

**The origin is `plot_00`, and the number is the point.** It is not the first
event in a chronology but the answer to a different question, so it sits outside
the sequence it precedes, and it can be prepended when found rather than forcing
a renumber of every plot and cross-reference — a cost four restagings paid in one
day. Verified that the canon, the validator and the registry all accept `plot_00`
before proposing it.

**The gate holds the fact and not the judgement.** That a culture has a `plot_00`
is decidable, so it is gated. Whether a given one is a true origin or a treaty
wearing the number is the dialogue `order_the_defining_question.md` protects, and
no counter can substitute. A reviewer who waves a founding through as a `plot_00`
has defeated the order with the gate still green, and that is the right division:
the machine cannot read.

**Narrow ratchet**, fired only when a change touches a culture's plots or its play
file. Coverage debt can be paid in a sentence; an origin is a research pass, and a
gate demanding one for a typo would be answered with a bad `plot_00`, which is
worse than none. Proven both ways: red on a touched plot line, silent on a
persona, a REFERENCES file or a test.

All 290 cultures lack one today. The order forbids a sweep — 290 origin files
written to satisfy a counter would be 290 passports.
