Render the tongues package's own docs instead of keeping them. The house has already paid once for a hand-maintained table about files it did not contain: the language-position manifest had drifted in seventeen places by the time anyone counted, and this package is going to hold 320 varieties. So the split is fixed now, at one variety rather than at fifty. What is derivable is derived from the files themselves, the variety list, each tongue's declared name and language, the count and the ordering; what is judged lives in `provenance.json`, written by whoever judged it: which culture wrote the variety, whether its prose still awaits a native reader, and what reading it against the position mnemonic found. `build.mjs --write` renders README and REFERENCES through prettier with the repo's own config, so the generator and the formatter cannot rewrite each other, and the package's own tests fail on any drift or on a variety with no provenance. Empty changeset: nothing here sits in the umbrella's files.
