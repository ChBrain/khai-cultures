Write down what earns a variety a file, because the house had already written four
that would not have earned one and each failed the same way: the better-known name
standing in for the actual tongue. The test is that the distinguishing feature can be
named and sourced — the rule stated as a rule, a minimal pair written on both sides,
categorical rather than gradient, and visible in writing, since a difference that
lives in intonation cannot go in a text file. One feature is enough when it runs
through every word, which is what makes Nordbairisch writable. This is a different
question from `review: "native"`, and the two get confused: that flag says no speaker
has read the prose, and it is the right answer to doubt about idiom. The hard stop is
prior — is there a system here to write at all — and no flag covers it. Also records
the three decisions that produced the test. Ostmittelbairisch gets no file: the
west/east split is real but gradient and anchored in Vienna's pull along the Danube,
not coterminous with Lower Bavaria, so Mittelbairisch stays one variety and
Niederbayern and the Wald become a place-and-persona question for the play instead.
Egerländisch gets no file yet, with four named criteria any one of which would earn
it. Alemannic gets a gate rather than a label. And the atlas sources are listed, so
the next hand reads attested prose rather than reconstructing it. Governance only;
the house ships nothing.
