**Twenty-seven units link `gsw`, and `gsw` is not Swiss.** Its own text says so:
it reaches _"vum Elsass über s Badische un s Schwäbische bis in d Schwiiz un uf
Vorarlberg"_, and it is written in a Badisch-leaning Alemannic - _nit_, _sundern_,
_vun_ - where Swiss writes _nöd_, _sondern_, _vo_. Alsace already has its own
sub-file under that anchor. Switzerland did not.

This adds `gsw/position_language_gsw_ch.md`, hanging from the `gsw` anchor beside
`gsw_fr`, for the same reason that one does: Swiss German is Alemannic in the way
Alsatian is, and the tree should say so.

## Every chapter says what the anchor does not

The anchor already holds the monophthongs, the missing preterite, the continuum
across three states, and **the absence of one Alemannic orthography**. None of
those is repeated here. What is left is what is Swiss:

|            |                                                                                                                                                                                                                                                                                                                                                                            |
| ---------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Has**    | All three Alemannic steps inside one small country - Low in Basel, High in the Mittelland, Highest in the Wallis and the Walser settlements past it. Seven large groups and village variation below them, so "Swiss German" is a political name and not a linguistic unit.                                                                                                 |
| **Orders** | A canton in every sentence, because there is no neutral Swiss German to stand behind. And the register above is not a more careful version of the same tongue but a different language, so there is no ladder - only a switch.                                                                                                                                             |
| **Loses**  | Its own roof. Swiss Standard German is nobody's mother tongue, which **this house already says**, holding `de_ch` on the `noMotherTongue` list. That leaves a speaker with a tongue they do not officially write and a tongue they never learned first - and an incomer who can finish the German book and still not be let in, because what is spoken inside has no book. |
| **Drives** | Dialect reports a place and never a rank. A doctor and a farmer from one valley sound alike, and nobody advances by softening their dialect, because there is no finer step above it. Giving it up is not a promotion; it is leaving home.                                                                                                                                 |

## One claim was checked and dropped before it was written

A draft said the federal parliament and the main news broadcast run in dialect.
**They do not** - Standard German is expected in both, and the diglossia is
_medial_: spoken Swiss German, written Swiss Standard German. The claim came from
memory and did not survive the sources, so it is not in the file.

## The orthography is Zurich-leaning, and that is not an accident it apologises for

Flagged `review: native`, like its two siblings. The lean is the file's own **Has**
demonstrated rather than neutrality lost: it says there is no Swiss German that
names no canton, so its own prose cannot name none either.
